## 열면 무엇을 누르나

열면 완성된 메뉴판이 그대로 뜹니다. 아래에 버튼 넷이 있습니다.

| 버튼 | 하는 일 |
|---|---|
| **편집** | 글자를 눌러 고칩니다. 이름 · 가격 · 설명을 바꾸고, 메뉴를 넣고 빼고 순서를 옮깁니다. 켜면 오른쪽에 **꾸미기** 창이 함께 열려 글꼴 · 색 · 단 수 · 그림을 고릅니다 |
| **저장** | 지금 모습 그대로 파일 하나가 내려받아집니다. **그 파일이 다음번 메뉴판**입니다 |
| **인쇄** | 인쇄 창이 열립니다. 화면에서 보던 모습 그대로 A4에 나옵니다 |
| **?** | 쓰는 방법 열 줄 |

편집 중에는 위에 **미리보기**가 생깁니다. 고치는 표시를 모두 걷고 인쇄될 모습만 보여 줍니다.

안 들어가는 것이 있으면 종이 아래에 붉은 띠가 서서, 어느 단이 무엇에 얼마나 겹치는지와 **글자를 몇 %로 낮추면 들어가는지**를 알려 줍니다.

## 왜 이런 모양인가

**쓰는 사람이 컴퓨터에 익숙하지 않은 가게 주인**입니다. 이 제약이 모든 결정의 기준이었습니다.

- **서버도 계정도 없습니다.** 로그인을 만들면 사장님이 아이디와 비밀번호를 관리해야 합니다. 그래서 저장을 "새 파일이 내려받아진다"는 파일 개념으로만 설명합니다
- **처음 보이는 버튼이 넷뿐입니다.** 고치는 일은 전부 편집 안에 넣었습니다. 고치는 곳이 두 군데가 되면 어느 쪽에 속하는지 애매한 것이 생깁니다
- **화면과 인쇄가 같습니다.** 프린터가 못 찍는 가장자리를 화면에서도 흰 테두리로 비워 두고, 그것을 뺀 나머지로 여백을 잡습니다. 처음에는 이걸 안 해서 인쇄물의 위아래가 잘렸습니다
- **크기는 사장님이 정합니다.** 안 들어가면 저절로 줄이지 않고 알려만 줍니다. 저절로 줄이는 기능을 네 번 만들었다가 네 번 다 걷어냈습니다

메뉴 장과 와인 장이 있고, 와인은 병 모양 아홉 가지와 색을 골라 카드로 보여 줍니다.

반대로 **하지 않기로 한 것**도 있습니다. 예약, 지도, 챗봇, 관리자 모드를 검토하고 넣지 않았습니다. 더 나은 서비스가 이미 있는데 억지로 넣으면 더 불편해지기 때문입니다.

## 어떻게 만들었나

코드를 직접 쓰지 않고 AI와 대화로 만들었습니다.

파일이 커지면서 대화가 여러 번 끊겨, **결정 기록 258건**과 인수인계 문서를 남겨 다음 대화에 넘기는 방식으로 이어 갔습니다. 무엇을 왜 그렇게 정했는지가 코드 주석에 번호로 붙어 있습니다.

AI가 "넣었습니다"라고 답하고 실제로는 안 들어간 일이 반복돼, 말 대신 눈으로 확인하는 **자동 검사 35종**을 따로 만들었습니다. 인쇄 여백을 mm로 재고, 저장했다 다시 연 파일에 특수문자를 섞어 보고, 버튼을 실제로 눌러 보고, 편집 화면과 완성본의 위치 차이를 0.0px까지 봅니다.

기능은 전부 사장님이 쓰면서 한 말에서 나왔습니다.
